# Состав учебной группы

`GET /v1/education/groups/{group_id}/members`

Публичный маршрут: JWT и проверка доступа к группе не требуются.
Единственный входной параметр — UUID группы в пути; тело запроса не нужно.

```json
{
  "success": true,
  "teachers": [
    {
      "id": "00000000-0000-0000-0000-000000000001",
      "first_name": "Иван",
      "last_name": "Иванов",
      "middle_name": "Иванович",
      "avatar_url": null
    }
  ],
  "students": []
}
```

`id` — ID пользователя (`auth.users.id`), а не членства в вузе.
Возвращаются только активные членства, явно привязанные к указанной группе
через `teacher_groups` или `student_groups`. Если человек имеет обе роли
в группе, он присутствует в обоих массивах.

Каждый массив отсортирован по фамилии, имени, отчеству и ID пользователя;
отсутствующие значения идут последними. Все поля участника присутствуют
в ответе; отсутствующие данные профиля возвращаются как `null`.
Для существующей пустой группы оба массива равны `[]`.

Ошибки:

- `400`: `{"success": false, "error": "invalid_group_id"}`.
- `404`: `{"success": false, "error": "group_not_found"}`.

Ответы содержат `Cache-Control: no-store`.
Реализация находится в `src/education/info`: хендлер, сервис и репозиторий.
